# Langdock Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Ask Langdock and Ask Agent: chat with streamed answers, follow-ups in the search bar and a model dropdown
- Agents are listed by name, with recently used agents first
- Selected text commands: Ask About Selection, Summarize, Translate, Improve Writing, Explain
- Ask About Files, Ask About Web Page and Ask About Screenshot
- Agents with input forms open a native form
- Chat History to search and continue conversations
- Search Prompts, Search Knowledge, Search Skills and Search Meetings
- Add to Knowledge Base and Run Integration Action
- Generate Image and Browse Generated Images
- Manage and Create Scheduled Tasks, and Browse Workflows
- Quicklinks for agents and prompts, and default models set from the model pickers
- Model and provider names, descriptions and logos as in Langdock
